## What 1.0.0 freezes

Breaking any of these is a 2.0.0, not a minor:

- The `R_*` error-code union is exactly **10** (R_BAD_COUNT, R_BAD_LENGTH,
  R_BAD_OFFSET, R_BAD_SCHEMA, R_BAD_SOURCE, R_BAD_STRIDE, R_BAD_TYPE,
  R_BUFFER_TOO_SMALL, R_DUPLICATE_FIELD, R_UNKNOWN_FIELD). Each is a documented,
  greppable `error.code`.
- The type-code table is exactly **8** (codes 0-7): T_F32=0, T_F64=1, T_I32=2,
  T_I16=3, T_I8=4, T_U32=5, T_U16=6, T_U8=7, byte-for-byte lite-bake's `Types`.
- The read surface: `getF64`..`getU8` / `get`; `seek` + `f64`..`u8` / `val`;
  `readRow`; `laneOf` (frozen `{view, elemStride, elemOffset}` + the decline
  contract); `bytes` (3-arg and the lengthField 2-arg); `field` / `typeOf` /
  `offsetOf` / the introspection getters; `fromBaked` / `fromLBK1Shard`.
- The contracts around them: fail-closed construction door, unchecked hot path,
  explicit endianness, `laneOf` never returns a wrong-endian/unaligned lane (declines
  to null), `bytes()` is a BORROWED view (copy what you keep), no import edge into any
  sibling, zero allocation on every read surface.
- All three inventories (code union, type table, version) are gated by
  `test/dts-drift.test.js` reading the TEXT of `Reader.js`, `Reader.d.ts`, and
  `package.json`, with mutation controls proving the gate has teeth.

## What stays open (additive, post-1.0)

These ADD surface; they do not change what 1.0.0 shipped. Each is its own minor with
its own torture gate:

- S9 (1.1.0): 64-bit integer lanes (i64/u64 via BigInt). This is the ONE place the
  frozen type-table count moves, 8 -> 10, updated in lock-step with the drift gate.
  BigInt reads box, so the zero-alloc claim is scoped honestly (laneOf over a
  BigInt64Array is the zero-alloc 64-bit path).
- S10 (1.2.0): optional per-field endianness (default = the reader flag, so existing
  schemas are byte-identical). Reuses R_BAD_SCHEMA; no new code.
- S11 (1.3.0): `.d.ts` record inference from a `const` schema (types only; Reader.js
  byte-identical).
- S12 (1.4.0): zero-alloc iterator sugar (`[Symbol.iterator]` yielding a reused row
  handle, torture-gated 0 B/op), and an OPTIONAL allocating `string()` cold hatch if
  the string boundary is decided to move.

On demand only: bitfields / sub-byte lanes, float16. Deliberate boundaries (NOT
gaps): no write/encode path (the bakers own writing), no nested / array-of-struct
DSL, no codegen.
